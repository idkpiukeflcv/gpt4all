## Overview

GPT4All is a free, privacy-first local AI chatbot by Nomic AI that runs quantized language models entirely on your own hardware — CPU or GPU — with no internet connection required. It supports a growing library of models, features LocalDocs for RAG-based document querying, and provides an OpenAI-compatible API for developer integrations.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **GPT4All** delivers the features you need in a clean, intuitive package.

> Official website: [nomic.ai](https://nomic.ai)

## Key Features

| Feature | Description |
|---------|-------------|
| **CPU and GPU** | Runs efficiently on both CPU only and GPU-accelerated hardware |
| **LocalDocs RAG** | Index local documents and query them via retrieval-augmented generation |
| **Model Library** | Curated library of verified, privacy-safe model downloads |
| **OpenAI API** | Local OpenAI-compatible API endpoint for developer tool integrations |
